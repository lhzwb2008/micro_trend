# 港股板块轮动趋势识别模型

识别"去年大消费、今年AI硬件"这类**板块级别的资金+动量主线趋势**，按月轮动持有最强板块，
在没有明显主线的时期自动清仓，用2018年至今、覆盖多个牛熊周期的回测验证有效性。

## 快速开始

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

.venv/bin/python get_hk_data.py               # 下载/更新数据
.venv/bin/python sector_rotation_backtest.py  # 跑回测，打印2025/2026每月持仓
```

## 文件

- `get_hk_data.py` — 数据下载脚本，增量缓存，重复运行只补齐缺失部分
- `sector_rotation_backtest.py` — 建模+回测：特征工程、板块聚类打分、主线离散度择时、持仓明细
- `data/` — 行情/南向资金/行业分类数据及回测输出（`data/cache/` 为下载缓存，可忽略）

## 策略逻辑

1. **股票池**：港股通成分股，按成交额取前200只
2. **行业聚类**：东财"所属行业"字段分成28个行业，成员数<4的归并为"其他"
3. **板块打分**：月末把个股特征（60日相对强度、60日动量、南向持股占比60日变化、
   20日/120日均成交额比）按行业等权聚合，再做等权分位数排名，选Top4板块
4. **持仓**：Top4板块，每个板块内只买个股评分最高的7只（平均持仓约21只）
5. **主线离散度过滤 = 择时**：板块之间60日相对强度的截面标准差，与最近36个月的滚动中位数
   比较——分化明显（有清晰的强弱主线）时满仓，分化不明显时**完全清仓**（102个月里
   约一半满仓、一半空仓）

## 数据源

| 数据 | 来源 | 历史长度 |
|---|---|---|
| 个股日线行情 | 新浪财经 `stock_hk_daily` | 1998起 ~ 最新（视个股上市时间） |
| 个股南向资金持仓 | 东方财富 `stock_hsgt_individual_em` | 约2024-07 ~ 最新（免费接口上限） |
| 行业分类 | 东方财富"所属行业" | 静态快照 |

2024-07之前南向资金特征用中性值填充，板块打分退化为"动量+相对强度+成交额趋势"三个维度。

## 关键结论

1. 板块聚合比个股选股更稳定——"选对板块"比"板块内精选"更重要，但板块内精选7只可以
   去掉评分较低的拖累项，在不牺牲收益的前提下降低持仓数。
2. **主线离散度过滤**是目前最有效的择时机制：判定无主线时完全清仓，比"减半仓位"更好；
   基准线必须用36个月滚动中位数，不能用从头算起的 expanding 中位数（会被早年小样本噪声污染）。
3. 过度集中（只留1个板块3只股票）会让回撤恶化到-60%以上，Top4×7只是当前测下来风险调整后
   收益最好的平衡点。
4. 策略更适合当作**主线板块识别工具**辅助判断，而不是完全自动化的实盘系统；2023年仍有
   -12%亏损，说明择时信号本身有滞后和误判。
