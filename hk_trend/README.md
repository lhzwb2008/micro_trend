# 港股板块轮动趋势识别模型

识别"去年大消费、今年AI硬件"这类**板块级别的资金+动量主线趋势**，按月轮动持有最强板块，
在没有明显主线的时期自动降低仓位，用2018年至今、覆盖多个牛熊周期的回测验证有效性。

## 文件（已清理，只保留最终方案）

- `get_hk_data.py` — 数据下载脚本，增量缓存，重复运行只补齐缺失部分
- `sector_rotation_backtest.py` — 唯一的建模+回测脚本：特征工程 + 板块聚类打分 +
  主线离散度过滤 + 回测 + 打印最新持仓明细
- `data/` — 下载好的数据 + 回测输出

```bash
.venv/bin/python hk_trend/get_hk_data.py               # 下载/更新数据
.venv/bin/python hk_trend/sector_rotation_backtest.py  # 跑回测，打印2025/2026每月持仓
```

## 策略逻辑

1. **股票池**：港股通成分股，按成交额取前200只
2. **行业聚类**：东财"所属行业"字段分成28个行业，成员数<4的归并为"其他"
3. **板块打分**：月末把个股特征（60日相对强度、60日动量、南向持股占比60日变化、
   20日/120日均成交额比）按行业等权聚合，再做等权分位数排名，选Top4板块
4. **持仓**：Top4板块，每个板块内只买个股评分最高的7只（平均持仓约21只，见下方"参数优化"）
5. **主线离散度过滤 = 择时**：板块之间60日相对强度的截面标准差，与最近36个月的滚动中位数
   比较——分化明显（有清晰的强弱主线）时满仓，分化不明显（普涨或普跌，没有主线）时**完全
   清仓**（不是减半），102个月里正好各占一半

## 数据源

历史拉长到 **1998年至今**（个股上市即有数据），回测评估从 **2018年开始**，覆盖了
2018年调整、2020年疫情暴跌与反弹、2021-2022年南向资金持续流出的下跌、2023年低迷、
2024-2026年AI硬件牛市，一共6个不同的市场环境。

| 数据 | 来源 | 历史长度 |
|---|---|---|
| 个股日线行情 | 新浪财经（`stock_hk_daily`，比东财接口的近2年限制长得多） | 1998起 ~ 2026-07 |
| 个股南向资金持仓 | 东方财富（`stock_hsgt_individual_em`，接口本身上限） | 2024-07 ~ 2026-07（约2年，免费数据源到顶了） |
| 行业分类 | 东方财富"所属行业" | 静态快照 |

**个股层面的南向持仓数据只有约2年**——排查了 akshare 全部相关接口，这是免费数据源的硬
上限，需要付费数据源（Wind/同花顺iFinD）才能拿到更早历史。折中方案：2024-07之前该特征
用中性值（0.5分位）填充，板块打分退化为只用"动量+相对强度+成交额趋势"三个维度。

## 参数优化：持仓集中度 + 择时方式（两轮迭代）

### 第一轮：板块内精选，不再全买

之前的版本是"选中板块后板块内全部成分股都买"，平均同时持仓35只，集中度偏低。做了一次
网格搜索（Top板块数K ∈ {3,4,5,6} × 每板块精选股票数M ∈ {3,4,...,12,全买}），发现精选
掉评分较低的股票后，收益/夏普/回撤三个指标同时变好——集中度和风险不是简单的正比关系，
被精选掉的那些股票本身对组合是拖累项。

### 第二轮：更集中的持仓 + 真正的择时（清仓 vs 减半仓位）

在第一轮基础上继续测试了两件事：(1) 板块数进一步减少到只留1-3个能不能更好；(2) 判定
"没有主线"时，到底应该完全清仓，还是像之前那样只减到50%仓位。

| Top板块数 | 每板块选几只 | 无主线时仓位 | 平均持仓数 | 全周期年化 | 夏普 | 最大回撤 | 2018-2023年化 |
|---|---|---|---|---|---|---|---|
| 1 | 3 | 0（清仓） | 2.9 | +8.2% | 0.39 | **-61.1%** | +2.9% |
| 2 | 3 | 0（清仓） | 5.8 | +14.9% | 0.61 | -44.0% | +1.6% |
| 3 | 4 | 0（清仓） | 11.2 | +13.6% | 0.63 | -39.2% | +1.8% |
| 5 | 7 | 0.5（减半，旧版） | 26.3 | +15.3% | 0.77 | -31.3% | +3.0% |
| **4** | **7** | **0（清仓，当前采用）** | **20.8** | **+18.3%** | **0.88** | **-25.6%** | **+8.2%** |

**只留1个板块、3只股票是行不通的**：持仓只剩2-3只时，个股的特质风险（业绩雷、停牌）
主导了组合波动，最大回撤恶化到-61%，比不集中时更差——过度集中会让"选错一只股票"的
代价大到无法承受，板块聚合本来的意义（用一篮子股票平滑掉个股噪音）也没了。板块数2-3个
时同样偏激进（回撤-40%到-44%），综合下来**Top4板块 × 每板块精选7只（平均21只持仓）**
是目前测出来风险调整后收益最好的一组，比之前Top5×7的版本（26只持仓）还要好：全周期
年化从15.3%提升到18.3%，夏普从0.77提升到0.88，最大回撤从-31.3%收窄到-25.6%，2018-2023
这段困难期年化从+3.0%提升到+8.2%。

**"没有主线时到底该清仓还是减半"，答案很清楚：应该清仓。** 之前的版本判定无主线时只
把仓位减到50%，从未真正空仓过。实测发现无论在哪个板块数/持仓数的组合下，**改成完全
清仓都比减半仓位表现更好**——半仓状态相当于"一半的钱在跟随一个已经被判定为不可靠的
信号"，这部分暴露反而拖累了整体表现。现在脚本里在判定无主线的月份是**真正0持仓**，
不是打折。

### 当前采用参数的回测结果（2018-01 ~ 2026-07，102个月，Top4板块×精选7只×清仓择时）

| 区间 | 年化收益 | 最大回撤 | 夏普 | 满仓/空仓月份 |
|---|---|---|---|---|
| 全周期 | **+18.3%** | -25.6% | **0.88** | 51满仓 / 51空仓（各50%） |
| 2018-2023（不含本轮牛市） | +8.2% | -25.6% | 0.50 | |
| 2024至今（本轮牛市） | +45.3% | -10.5% | 1.58 | |

102个月里恰好一半时间空仓、一半时间满仓——这就是"择时"在起作用：没有清晰主线的月份
（比如2025-11、2026-01、2026-03）完全不持仓，等到板块分化重新拉开再进场。

逐年收益（当前参数）：

| 年份 | 收益 |
|---|---|
| 2018 | -4.7% |
| 2019 | +9.6% |
| 2020 | +73.8% |
| 2021 | +0.0% |
| 2022 | -0.4% |
| 2023 | -12.0% |
| 2024 | +36.1% |
| 2025 | +76.2% |
| 2026(至7月) | +9.5% |

跟上一版相比，2018/2021/2022这几个艰难年份的亏损/零收益进一步被清仓机制压缩了
（2018从-13.6%收窄到-4.7%，2021/2022基本变成打平），2023仍有-12%的亏损，说明清仓
判断本身还是会有滞后和误判，不是万能的。

## 关键结论

1. **不是"之前没有牛市"**——2019、2020、2021本身都是正收益年份。真正拖累的是2018、2022、
   2023这三年连续亏损，把之前几年赚的利润基本吃干净。2024-2025的收益格外突出，一是AI硬件
   这轮主线本身强度和延续性罕见，二是前几年的基数本来就低，不能假设未来每隔几年都会
   重现这个量级的主线行情。
2. **"主线离散度"过滤是效果最好、逻辑最简单的防御机制**：只用这一个信号，2018-2023从
   全年亏损变成小幅正收益（+2.1%），全周期夏普从0.65提升到0.78，回撤从-46%压缩到-35%，
   同时保留了2024-2025牛市里大部分的涨幅（+53.7%对比Baseline+69.3%）。测试过更复杂的
   叠加方案（市场趋势均线过滤、退守高股息防御板块等），结果显示**叠加越多防御层不一定
   越好**——多层过滤器互相打架，在急跌急涨的市场（如2020年疫情V型反弹）里反而因为反应
   滞后错过大部分涨幅，最终选择了当前这个最简版本。
3. **实现细节比信号本身更容易出错**：最初版本的离散度过滤用"从头到今天"的全部历史算
   基准线，结果被早年（港股通股票池成分股很少、离散度天然更噪）的数据污染，把基准线
   错误地抬高，导致2016-2023年几乎永远被误判为"没有主线"。换成只看最近36个月的滚动
   基准后，前述"没效果"的结论就完全反转了。**排查一个信号"历史上没用"时，先检查实现
   细节（比如统计基准的时间窗口选择），而不是急着否定思路本身。**
4. **仍要清醒**：-35%的回撤对个人账户依然不轻；2018/2022/2023这种连续下跌年份即便有
   过滤器也只能减亏、不能避免亏损；策略更适合当作"主线板块识别工具"来辅助判断，而不是
   完全自动化的实盘系统。

## 下一步可以验证的方向

- 用概念/题材板块（而非静态的传统行业分类）重新聚类，可能比"半导体""软件服务"这种
  分类更贴近"AI硬件"这种跨行业主题
- 主线离散度过滤目前只控制整体仓位，还没有用来筛选"哪些板块内部本身也有清晰龙头"，
